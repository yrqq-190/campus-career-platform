## G10（D3 11.14 结束）——依赖与风险闸口

| 判定项 | 通过标准 | 不通过怎么处理 |
|---|---|---|
| 依赖方向 | 只有 展示→API→服务→数据 单向，零反向 | 画错的人当场改，改完重跑 |
| 循环依赖 | 依赖图中无环 | 有环即判不通过，不允许拖到下周 |
| 契约五要素 | 8 节全部含 URL / 请求 / 成功 / 失败 / 错误码 | 缺一项即打回该作者，不接受口头补充 |
| 风险表 | 每条含 影响 / 应对 / 负责人 / 验证方式 四列 | 缺「验证方式」的一律重写 |
| spike 计划 | 有目标、步骤、成功标准、结论 四要素 | 只有步骤没有成功标准的，判未完成 |
