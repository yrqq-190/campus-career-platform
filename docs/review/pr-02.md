1. **第 6 条缺口是流程性的，不是代码问题**。评审人给了 APPROVED 但没写逐条 AC 结论，`docs/pr-gate.md` 第 6 条实质空转。建议后续 PR 由评审人直接在 review body 里贴「AC 表 + 结论」，避免记录人代劳后再被追问出处。

4. **`GlobalExceptionHandler` 的改动属公共层**，`+29/−2` 会影响其他模块的错误响应；建议合并后由 T2 主笔确认没有覆盖 #119 里的兜底规则（尤其 422 被兜底成 500 这条已在本 PR 测试中暴露过）。
