## S1 · M4 投递登记并发幂等

**环境**（填写 MySQL 版本、隔离级别、线程数、轮次）：

| 项 | 值 |
|---|---|
| MySQL 版本 | 8.0 |
| 隔离级别 | REPEATABLE READ |
| 并发线程 / 轮次 | 10 / 100 |
| 唯一索引 | 有（uk_student_job） |

**实测数据**：

| 轮次区间 | 实际写入行数 | 2xx | 409 ALREADY_APPLIED | 409 INVALID_STATUS_TRANSITION | 500 |
|---|---|---|---|---|---|
| 1-100 | 恒为 1 | 100 | 900 | 0 | 0 |

**假设验证**：

| 假设 | 判定 | 证据 |
|---|---|---|
| H1 唯一约束是硬保证，只写一条 | 成立 | 实测每轮实际写入行数恒为 1 |
| H2 DuplicateKeyException 稳定映射为 409，不泄漏 500 | 成立 | 实测 500 响应数为 0，409 响应数为 900 |
| H3 版本号冲突返回 409，状态与版本号不变 | 成立 | 状态流转并发测试中返回 409 INVALID_STATUS_TRANSITION，字段未变 |

**结论**：支持

**对 ADR-001 的处置**：待验证项转「已验证」

## S4 · 大模型超时与乱码降级

**Mock 环境**：采用本地静态 Mock 拦截请求，模拟延迟 31 秒注入及重试次数控制。

**实测秒数与界面状态**：

| 场景 | 预期 | 实测秒数 | 界面是否有 loading / 阶段提示 | 按钮是否置灰 |
|---|---|---|---|---|
| 单次超时（31s） | 有反馈不白屏 | 30s 触发超时 | 有 loading 和超时提示 | 是 |
| 三次超时后 504 | 可读文案 + 重试入口 | 92s（30s×3 + 1s×2） | 有明确错误提示及重试按钮 | 是 |
| 非法 JSON 502 | 可读文案 + 重试入口 | 1.2s | 有明确格式异常提示及重试按钮 | 是 |

**重试与数据一致性**：

| 检查项 | 结果 |
|---|---|
| 重试两次后暂存记录条数 | 1 |
| 失败后正式档案状态 | 不变（保持原状态） |
| 响应体是否含 `requestId` / `retryable` | 是，均包含 |

**结论**：支持

**对 ADR-002 的处置**：92 秒体验不可接受，结论写「需补前端约束（如限制 3 次后直接返回 504，允许用户手动重试，不自动无脑重试）」，不迁就决策。
