## 一、仅依据该文件的回答

**这条记录不存在投递状态——系统不会因点击外链自动创建或变更投递状态，该岗位在学生的意向清单里没有条目，直到学生手动登记后才产生「已投递」。**

依据：

1. AC-4：Given「学生点击了外部岗位链接」，When「返回系统查看」，Then「该岗位状态不得自动变为『已投递』，必须由学生手动登记」。
2. FR-3 同义重申「点击外链跳转时，系统不得自动将该岗位记为『已投递』，必须由学生手动确认或操作登记」。
3. 摘要首句「点击外链不自动记为已投递」。

因此本题的答案是「无状态 / 无记录」，而不是四个状态中的任何一个。

## 二、判定与缺陷

- 主路径可回答，冷启动者不会误实现成「自动记为已投递」。

**残留边界（不阻断，但会让实现分叉）**：点击外链这一动作本身**是否留下记录**，文件没有写。`context.md` 术语表定义了「跳转记录 = 跳转时留下的检索条件，不含岗位详情」，但 M4 未引用该术语。冷启动者可能实现成「什么都不留」，也可能实现成「留一条跳转记录」。

## 三、修复建议

补一句：「点击外链仅写入跳转记录（检索条件，不含岗位详情），不创建投递记录；投递记录由学生手动登记时创建，初始状态为『已投递』。」
