## 一、仅依据该文件的回答

**给出同关键词重检的兜底提示，并在该条记录上标记来源；列表与页面不崩溃，不影响其他条目。**

2. 边界表第 4 行「外链失效或来源不可达 → 提供同关键词重检兜底，标记来源」，对应 AC-4。
3. 摘要中「针对外链失效、来源不可达……提供关键词重检兜底与空状态提示，不允许静默失败」。
4. 与 `context.md` 风险表「外链失效 → 留关键词与来源，提供同词重检兜底」一致。

「不允许静默失败」这一句还回答了「能不能直接跳过不提示」——不能。
