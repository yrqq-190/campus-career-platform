## 3. 处理规则

1. 每条必须有「已改（指向哪次提交）」或「不采纳（写明理由）」；空白条目视为未处理，D3 不得进 G10。
2. 涉及契约与 spec 冲突的（R-03/R-04/R-05），改动必须同时落到 spec，不允许只改架构。
3. 涉及 ADR 结论的（R-08），由 S1 探针结论决定，不由评审意见直接改决策。
4. 汇总表在 D3 收口时更新为 v2，作为 G10「环状评审意见清零」的证据。
