## 4. 处理规则

1. 每条必须有「已改（指向提交）」或「不采纳（写明理由）」；空白视为未处理，D3 不得进 G10。
2. 涉及契约与 spec 冲突的（N-02），三处（契约 / spec / ADR）必须同时改，不允许只改一处。
3. 涉及 ADR 结论的（R-08），由 S1 探针结论决定，不由评审意见直接改决策。
4. N-01 属安全问题，不因「MVP1 校内演示」而豁免——服务端替用户发请求，风险与部署规模无关。
5. 本表 D3 收口时更新为 v3，作为 G10「环状评审意见清零」的证据。
