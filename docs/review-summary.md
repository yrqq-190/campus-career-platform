## 6. 处理规则

1. 每条必须有「已改（指向提交）」或「不采纳（写明理由）」；空白视为未处理。
2. 涉及契约与 spec 冲突的（N-02 / N-11），三处（契约 / spec / ADR）必须同时改，不允许只改一处。**N-11 已于 11-15 双面归零闭环。**
3. 涉及 ADR 结论的（R-08 / R-16），由 S1 探针结论决定，不由评审意见直接改决策。**S1 已实测支持**，故 ADR-001 决策本身无需调整，但契约仍须补落地写法。
4. N-01 属安全问题，不因「MVP1 校内演示」而豁免。
5. **N-09 的防护规则全组生效**：push 前先 pull 最新 head；禁止 force push；分支只接受 PR 合并。
6. **D4 新增**：口径变更（M6 撤码，N-13）必须由陈雪在对照表留一句确认，否则 D4 之后仍按未处理计。
7. 本表 v5.1 后仍有 **3 条未改**（R-08 / R-13 / R-16），R-06 降为部分，逐条写明「为什么可以带病进第 4 周」或「补齐时限」，不留空。
8. **v5.1 新增**：判断「某节写没写」必须在**该节段内**取命中，全文命中只能证明「别处写了」。v5 的 N-05 误判即由违反此条产生。
