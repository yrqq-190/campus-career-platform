# Campus Career Platform

校级学生求职发展平台，面向高校学生提供求职准备与过程管理支持，连接简历整理、职业画像、岗位推荐、模拟面试、面试提醒与求职复盘。

岗位浏览、沟通与投递通过 BOSS 直聘外链完成。平台侧重学生的准备质量与求职记录，不维护第三方岗位详情。

## 仓库内容

本仓库提供产品范围、功能规格、目录约定与贡献模板，不包含可启动的业务应用。下列功能表描述产品范围，不代表功能已经实现。部署说明与构建命令应随可运行的实现提供。

## 产品范围

| 模块 | 功能说明 |
| --- | --- |
| 简历与档案 | 上传并解析简历，允许手动修改结构化结果 |
| 职业画像 | 完成霍兰德职业兴趣问卷，生成求职画像 |
| 岗位推荐 | 展示匹配度与推荐理由，点击卡片跳转 BOSS 直聘 |
| 投递记录 | 登记已投递、已查看、已约面、已结束四种状态 |
| 模拟面试 | 文字作答，覆盖岗位解析、提问、问答、评分与报告归档 |
| 面试日程 | 登记面试、四级提醒及 .ics 日历导出 |
| 面经检索 | 按条件筛选第三方面经链接，访问原始来源 |
| 求职看板 | 汇总个人求职档案与准备进展 |

就业指导中心仅提供只读看板；页面采用响应式布局。完整范围及限制见 [项目上下文](context.md) 和 [MVP 功能规格](spec/mvp-scope.md)。

## 范围限制

- 不建设自有岗位库，不提供站内投递或企业招聘管理。
- 不抓取或缓存 BOSS 直聘数据，不复制第三方面经正文。
- 不提供在线笔试、视频面试、摄像头行为或仪态分析。
- 不提供录用概率预测、社区或私信；语音不纳入 MVP1。
- 不设置企业补充入口，中心看板不提供内容审核、通知发布等写操作。

## 参与贡献

请先阅读 [贡献指南](CONTRIBUTING.md)。问题报告应提供可复现的信息，功能建议应说明用户需求与验收条件。涉及范围变化的提案须明确与既有规格的关系。

演示数据应为合成数据并明确标注；请勿提交真实简历、联系方式、访问凭据或其他敏感信息。
