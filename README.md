# campus-career-platform

校级学生求职发展平台：面向全校学生的一站式求职准备工具，覆盖简历解析、职业画像、岗位推荐、模拟面试、面试日程提醒与面经聚合。

## 目录结构

| 目录/文件 | 用途 |
| --- | --- |
| `context.md` | 项目业务边界、用户场景、MVP 范围与 Non-Goals |
| `agent-rules.md` | AI 协作规则：代码风格、架构红线、安全约束、构建命令 |
| `spec/` | 功能规格说明 |
| `adr/` | 架构决策记录 |
| `plans/` | 迭代计划与任务拆解 |
| `src/` | 源代码（本周不写业务代码） |
| `tests/` | 测试（本周不写业务代码） |
| `docs/spike/` | 技术探针与可行性试验 |

## 红线

- 本周 `src/` 与 `tests/` 不提交业务代码，技术探针只能放在 `docs/spike/`。
