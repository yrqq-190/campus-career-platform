# module-07 面经外链与筛选

> 负责人：熊尚华｜阶段：D7（补 AC 与边界异常表）

## 摘要

本模块负责把外部公开的面经资源以「外链 + 筛选」的方式聚合给学生，
是求职链路中的辅助查询环节，依赖 M2 求职画像提供方向上下文。学生可按
岗位、方向、来源等条件筛选面经列表，点击卡片即跳转到面经的原始发布页面；
平台只保存指向原始来源的链接与检索条件，并在每条记录上明确标注来源，
不复制、不缓存、不转载面经正文。针对外链失效、来源不可达、无匹配结果等
情形，提供关键词重检兜底与空状态提示，不允许静默失败；演示数据须显式
标注「演示数据」。本模块只做面经的外链聚合、筛选与跳转，不生产面经正文、
不提供站内评论与社区互动、不做录用概率预测，也不替代岗位推荐与投递登记。

## 用户故事

- 作为求职的学生，我想要按岗位、方向、来源筛选面经，以便快速找到与我目标相关的经验。
- 作为求职的学生，我想要点击面经就跳转到原始发布页面，以便阅读完整内容。
- 作为求职的学生，我想要优先看到与我画像方向相关的面经，以便参考更对口的经验。

## AC

- AC-1（正常）：Given 学生输入岗位、方向、来源等筛选条件，When 系统执行筛选，Then 列表应实时返回符合条件的面经，每条记录标注来源且仅含外链、不含正文。
- AC-2（正常）：Given 学生点击某条面经卡片且外链有效，When 系统响应，Then 应打开该面经的原始发布页面。
- AC-3（边界）：Given 筛选无匹配结果，或 M2 画像方向缺失，When 系统返回结果，Then 应展示空状态或默认列表、仍支持手动筛选，不报错崩溃。
- AC-4（异常）：Given 某条面经外链已失效或来源不可达，When 学生点击，Then 系统应提供同关键词重检的兜底提示并标记该来源。
- AC-5（异常）：Given 列表中包含演示数据，When 展示给学生，Then 演示数据必须带有「演示数据」标识，不与真实数据混用。

## 功能需求

### US-1 → FR-1 ～ FR-2

**FR-1**：系统应支持按岗位、方向、来源等条件筛选面经列表，并实时返回筛选结果。

**FR-2**：每条面经记录必须标注来源，且只保存指向原始页面的外链与检索条件，不存储正文。

### US-2 → FR-3

**FR-3**：点击面经卡片应打开原始外链；当外链失效或不可达时，提供同关键词重检的兜底提示并标记来源。

### US-3 → FR-4 ～ FR-5

**FR-4**：系统基于 M2 画像的方向标签对相关面经做优先排序，仅做外链聚合，不复制正文。

**FR-5**：演示数据在列表中必须带有「演示数据」标识，不与真实数据混用。

## 边界与异常

| 场景 | 预期行为 | 对应 AC |
| :--- | :--- | :--- |
| 筛选无匹配结果 | 展示空状态提示，不崩溃 | AC-3 |
| M2 画像方向缺失 | 不做个性化排序，给默认列表并支持手动筛选 | AC-3 |
| 外链失效或来源不可达 | 提供同关键词重检兜底，标记来源 | AC-4 |
| 演示数据混入 | 展示「演示数据」标识，不与真实数据混用 | AC-5 |
