# MVP1 范围（范围级）

本文件只回答「第一版做到哪、由哪些模块组成、谁负责、依赖谁」。
模块细节（用户故事、AC、边界与异常、功能需求）写在各自的 module 文件中，不在本文件重复。

## 一句话演示路径

学生上传简历 → 系统解析并逐项确认 → 做霍兰德问卷得画像 → 看到匹配岗位与理由 →
跳 BOSS 投递 → 回平台登记投递状态 → 文字模拟面试 → 登记面试并按多级提醒到面 →
面后复盘 → 在档案看板看到全过程记录。

## 术语与提醒基准（口径唯一，各模块不得另造说法）

- 统一称「多级提醒」：前 3 天、前 1 天、前 2 小时、前 30 分钟四个节点，加结束后复盘，共 5 次触发。
- 计算基准：前 3 天 / 前 1 天 / 前 30 分钟按**面试开始时间**；前 2 小时按**出发时间**。
- 具体渠道（站内信 + 邮件 + .ics）、返回码与异常处理写在 module-06，不在本文件展开。
