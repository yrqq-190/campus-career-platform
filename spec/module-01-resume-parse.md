# module-01 简历上传与解析

> 负责人：贾小舒｜阶段：D5 骨架（仅填摘要，D6 补用户故事与功能需求）

## 摘要

本模块负责把学生上传的简历文件转成结构化求职档案，
是求职画像的数据起点。学生在建档页面上传 PDF 
或 Word 格式的简历，系统保存文件后调用大模型抽取教育
背景、专业技能、项目经历、实习经历四类字段，以结构化
JSON 返回前端渲染。解析结果必须经学生逐项核对与
修改、由学生显式确认后才写入档案，机器识别结果不直接
生效。格式不支持、文件超限、解析超时、模型输出无法通过结构
校验、未抽到任何有效字段等情形，一律返回明确错误码与提示，
不允许静默失败。本模块只覆盖简历的接收、解析、人工确认与替换
，不生成求职画像、不做岗位匹配、不解析非简历文档，
也不保存或比对多份简历的历史版本。
