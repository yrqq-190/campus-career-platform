# module-03 岗位推荐与外链

## 摘要

本模块负责根据学生画像推荐岗位并展示外链。推荐结果需可解释，能说明命中了哪些技能或方向；外链仅作跳转，不代替投递登记。

## 用户故事

- 作为求职的学生，我想要在岗位推荐列表中看到推荐理由（例如命中了哪些技能），以便判断该岗位是否值得投递。
- 作为求职的学生，我想要点击岗位卡片直接跳转到外部招聘链接，以便去官方渠道查看详情并投递。

## AC

- AC-1（正常）：Given 学生画像中有“Java”技能且岗位要求包含“Java”，When 系统生成推荐列表，Then 推荐卡片上必须展示“命中 Java 技能”的推荐理由。
- AC-2（边界）：Given 学生画像中无任何技能标签（缺字段），When 系统请求推荐列表，Then 系统应展示【暂无匹配岗位，请完善技能标签】的空状态提示，不得报错崩溃。
- AC-3（异常）：Given 某个岗位的外链已经失效，When 用户点击该外链，Then 系统应弹出提示【该链接可能已失效，已为您按关键词重新检索】并提供重检链接，同时在卡片上标记“失效来源”。
- AC-4（异常）：Given 岗位数据来源为演示数据，When 在推荐列表中展示，Then 必须带有“演示数据”的明确标识。

## 功能需求

- FR-1：系统应根据学生画像（性格倾向、能力标签、意向方向）与岗位要求进行匹配，生成推荐列表，并给出匹配度。
- FR-2：推荐卡片上必须展示可解释的推荐理由，明确说明命中的技能或方向标签。
- FR-3：点击岗位卡片可跳转至外部招聘链接，仅记录跳转条件（检索条件），不得在本地存储岗位详情数据。
- FR-4：外链仅作跳转，不得在本模块内自动修改投递状态。

## 非功能需求

- NFR-1：外链跳转响应时间不超过 1 秒。
- NFR-2：推荐列表加载时，需确保演示数据的标识清晰可见，不误导用户。

## 边界与异常

| 场景 | 预期行为 | 对应 AC |
| :--- | :--- | :--- |
| 画像缺字段 | 推荐理由展示兜底文案，不崩溃 | AC-2 |
| 无匹配岗位 | 展示空状态提示 | AC-2 |
| 外链失效 | 提供关键词重检提示，标注来源 | AC-3 |
| 演示数据混入 | 卡片展示“演示数据”标识 | AC-4 |

## Non-Goals

- 不负责保存岗位详情数据。
- 不负责自动登记投递状态。
- 不负责处理文件上传，局约定的 MAX_RESUME_SIZE=10MB 由 M1 模块负责，本模块不受理。
